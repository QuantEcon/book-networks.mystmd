## About this repository

The pages are **generated**. They are converted from the book's LaTeX source,
which is kept in a separate repository, with
[claude-latex-to-myst](https://github.com/QuantEcon/claude-latex-to-myst), and
built with [MyST](https://mystmd.org) (QuantEcon's fork). Every publish
replaces the content here, so edits made directly in this repository are lost;
corrections go into the LaTeX source.

The site is deployed by `.github/workflows/deploy.yml` on every push to `main`.
